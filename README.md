# courier

An HTTP client for Pony, built on [lori](https://github.com/ponylang/lori).

## Status

courier is pre-alpha software under active development. The API is not yet defined.

## Installation

* Install [corral](https://github.com/ponylang/corral)
* `corral add github.com/ponylang/courier.git --version 0.0.0`
* `corral fetch` to fetch your dependencies
* `use "courier"` to include this package
* `corral run -- ponyc` to compile your application

You'll also need a SSL library installed on your platform. See the [net-ssl](https://github.com/ponylang/net-ssl) installation instructions for details.
